Hydra-Audit · Available

Byzantine Fault Detection & Timestamp Integrity

Distributed systems fail in non-obvious ways — clocks drift, nodes lie, audit logs get tampered. Hydra-Audit provides cryptographic proof of when events occurred, detects Byzantine timestamp manipulation, and produces an immutable audit chain anchored to multiple independent time sources.

Verification engine, REST API, and npm package — drop into any pipeline.

How it works

  • 01 Event payload is submitted to the audit endpoint with a context ID.
  • 02 Time anchor is collected from multiple independent sources and bound to the payload.
  • 03 Ed25519 commitment is generated. HMAC chain links events in sequence.
  • 04 Any later verification call detects drift, replay, or Byzantine manipulation.

Attack types detected

  • REPLAYToken submitted more than once — signature already seen.
  • DRIFTTimestamp exceeds acceptable drift window from multi-source anchors.
  • FORGEEd25519 signature mismatch — payload modified or cross-pool submission.
  • FLOODRate limit exceeded for this IP.
  • ORDERINGTimestamp precedes last seen token for this context.

API reference

  • POST /api/demo/pot/generate — Public demo. No API key. Returns PoT token.
  • POST /api/demo/pot/verify — Public demo verification. Paste full generate response.
  • POST /api/pot/generate — Production. Requires X-API-Key header.
  • POST /api/pot/verify — Production verification. Requires X-API-Key header.
